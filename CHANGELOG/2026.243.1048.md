# 2026.243.1048 — feat(WP5): lock the desktop once the last viewer has been gone long enough

## Summary

**WP5's last open item: lock/idle.** A streamed desktop has no lid to close and no seat to lock
from — when the last WebRTC consumer disconnects, the session stays logged in and rendering, and
whoever reconnects lands straight in it. This arms `hyprlock` after a configured idle period.

Opt-in via `CSTREAM_LOCK_AFTER=<seconds>`.

## Three things measured on a live pod, because each had a plausible wrong answer

**1. The streamer cannot spawn `hyprlock` itself.** It is the Wayland *parent*, and Hyprland nests
inside it on a different display — a lock spawned from this process would attach to the wrong
compositor. It has to be dispatched *into* Hyprland.

**2. The IPC socket is discoverable, under our own runtime dir.**
`$XDG_RUNTIME_DIR/hypr/<signature>/.socket.sock`. The signature is **not** in Hyprland's
`/proc/<pid>/environ` — an env probe finds nothing, the same trap `plugin-wl` documents — but this
process owns that `XDG_RUNTIME_DIR`, so it can be read off the directory listing:

```
$ ls /tmp/cstream-rt/hypr
efb50993780079460b0cbed1363e2166a2de1d9f_1788172148_2020846053
```

**3. The dispatcher is `exec_raw`, not `exec`.** Hyprland ≥ 0.55 replaced string dispatchers with
Lua. Measured, in order:

```
hyprctl dispatch 'hl.dsp.exec("hyprlock")'
  error: attempt to call a nil value (field 'exec')

hyprctl dispatch 'exec hyprlock'
  error: [string "return hl.dispatch(exec hyprlock)"]:1: ')' expected near 'hyprlock'

hyprctl repl 'for k in pairs(hl.dsp) …'
  cursor dpms event exec_cmd exec_raw exit focus force_idle … window workspace
```

Both `exec_cmd` and `exec_raw` launch it; `exec_raw` is used because the command is a fixed binary
with no arguments, so raw exec avoids any shell interpretation of the string.

## How tested

**The wire format, end to end on the live pod.** The exact byte string this module sends, over the
raw Unix socket with no framing — not via `hyprctl`:

```
$ printf 'dispatch hl.dsp.exec_raw("hyprlock")' | socat - UNIX-CONNECT:…/.socket.sock
ok
$ pgrep -a hyprlock
328 hyprlock
```

That is the part I would otherwise have gotten wrong three times: nil dispatcher, syntax error, or
silent no-op. `pgrep` rather than absence-of-error, because a wrong Lua key returns `nil` quietly.

### What is NOT claimed

**`arm()` has not run against a real consumer.** The dispatch half is proven live; the half that
wires it to `webrtcsink`'s `consumer-added`/`consumer-removed` signals is not — those signals exist
(verified with `gst-inspect` on the pod) but nothing has yet driven them by connecting and
disconnecting a viewer. That is `pod-cstream`'s bed gate, and the tier below reflects it.

## Design notes

**Opt-in, and a malformed value refuses to arm — loudly.** "Never lock" is the security-relevant
direction to fail in silently, so `CSTREAM_LOCK_AFTER=banana` prints that the desktop will not
auto-lock rather than quietly disabling.

**Every failure path logs and returns.** This process is the Wayland parent; losing a *lock* is not
worth losing the session someone is still watching. That is the same proportionality that made the
audio branch opt-in after a fatal error path killed the parent — the lesson is applied here rather
than relearned.

**The socket is discovered per lock, not cached at startup**, because Hyprland can restart under us
and a signature cached from a dead instance would send every future lock into a socket nobody is
listening on. `discover` also skips instance directories with no `.socket.sock` for the same reason.

## Rulebook compliance

- **R1 — RCA every anomaly.** Two wrong dispatch spellings were measured and are recorded with their
  exact errors rather than silently discarded.
- **R3 — no duplication.** One dispatch path; the tracker holds the policy, the glue holds none.
- **R4 — no workarounds.** No sleeps beyond the poll interval, no retry loops; the lock fires once
  and reports refusal.
- **R6 — git safety.** Branched off merged `main`; clean tree after commit; no force-push, no direct
  push to `main`, no hook bypass.
- **R7 — prove the gate, not the plan.** Gate output pasted from the final committed tree, plus the
  live socket transcript.
